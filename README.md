# 🕌 MasjidStory - Backend

> ASP.NET Core 8 Web API for MasjidStory, a full-stack platform that helps users discover mosques, share Islamic stories, join communities, and explore events through an interactive and multilingual experience.

# 📖 About The Project

MasjidStory is a full-stack web application developed for a real client to create an online platform that connects Muslims around the world through mosques, stories, communities, and events.

The backend provides secure RESTful APIs consumed by an Angular 19 frontend while handling authentication, authorization, business logic, data persistence, validation, and file management.

# ⚙️ Getting Started

```bash
git clone <repository-url>

cd MasjidStoryProject-Backend
```

Update the connection string inside:

```
appsettings.json
```

Run migrations

```
Update-Database
```

Run the application

```
dotnet run
```
